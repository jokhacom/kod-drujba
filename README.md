# Код дружбы — лендинг маршрута

Одностраничный сайт международного туристического маршрута «Код дружбы» (Международная школа Студтуризма): Казахстан, Кыргызстан, Таджикистан, Узбекистан, Армения. 5 стран, 9 дней.

**Превью:** https://jokhacom.github.io/kod-drujba/

## Что внутри
- `index.html` — разметка, SEO-мета, Open Graph, JSON-LD.
- `data/routes.json` — **все данные маршрута** (страны, дни, точки, время, координаты, фото, AR, команда, контакты) на RU и EN. Чтобы поправить программу, меняйте только этот файл.
- `assets/js/app.js` — рендер, карта (Leaflet + OpenStreetMap), вкладки дней, галерея с лайтбоксом, AR (model-viewer), переключатель RU/EN.
- `assets/css/styles.css` — стили (mobile-first, палитра: бирюза, золото, глубокий синий, песочный).
- `assets/img/` — фото (webp, полный размер и `-sm`).
- `assets/models/` — 3D-макеты для AR (`.glb`), генерируются `scripts/make_models.py`.
- `assets/vendor/` — Leaflet 1.9.4, model-viewer 3.5.0, qrcode-generator 1.4.4 (лежат локально, чтобы не зависеть от CDN).

Сборка не нужна: это статический сайт. Локально: `python3 -m http.server` и открыть http://localhost:8000.

## Как добавить фото
1. Положите `name.webp` и `name-sm.webp` (≈640 px) в `assets/img/<страна>/`.
2. В `routes.json` у точки укажите:
   ```json
   "photo": { "src": "assets/img/uz/registan.webp", "sm": "assets/img/uz/registan-sm.webp",
              "author": "Имя автора", "license": "CC BY-SA 4.0", "url": "ссылка на источник" }
   ```
   Строка вида `"photo": "kz/kz_medeu"` означает собственное фото проекта (автор берётся из `meta.photoCredit`).
   Точки без фото с бейджем «Главное» показываются заглушкой.

## Как заменить AR-модели
Положите детальную модель с тем же именем в `assets/models/` (`registan.glb`, `cascade.glb`, `medeu.glb`). Для iOS model-viewer сам сделает USDZ.
